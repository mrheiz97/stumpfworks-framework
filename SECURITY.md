# Security Policy

StumpfWorks Framework is currently pre-1.0 and is not yet recommended for
production use. The detailed policy is maintained in
[`docs/SECURITY.md`](docs/SECURITY.md).

Please report suspected vulnerabilities privately to
[hello@stumpfworks.de](mailto:hello@stumpfworks.de). Do not disclose
credentials, personal data, or working exploits in public issues.
